# Reel music

Put 3-10 royalty-free tracks here (`.mp3` or `.m4a`). One is picked per day, in rotation.

Use only music you're allowed to use on Instagram, e.g. tracks from the Pixabay Music library
(free under the Pixabay Content License) or the YouTube Audio Library tracks marked 'no attribution required'.
If this folder has no tracks, Reels are posted without music.
